# Alexis Deighton MacIntyre — academic website

A lightweight, responsive academic homepage built with plain HTML and CSS for GitHub Pages.

## Files

- `index.html` — homepage and page sections
- `style.css` — responsive styling
- `assets/profile.jpg` — supplied profile photograph
- `assets/Alexis_Deighton_MacIntyre_CV.pdf` — supplied CV

## Publish with GitHub Pages

1. Upload the contents of this folder to the root of the repository.
2. In GitHub, open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Choose the `main` branch and the `/ (root)` folder, then save.
5. Wait for the deployment to finish. GitHub notes that publication can take up to 10 minutes.

The site uses relative asset links, so it works from a project-site path as well as a user-site root.

## Before publishing

Please review the biography, research descriptions and publication formatting. The text was assembled from the supplied CV and the existing website pages. Check any details you want to update, and consider adding your preferred Google Scholar / ORCID / LinkedIn URLs.

## Repository naming

For a personal user site at `https://alexisdmacintyre.github.io/`, GitHub requires the repository to be named `alexisdmacintyre.github.io`.

If you keep the current repository name `alexisdmacintyre`, the project site address will be `https://alexisdmacintyre.github.io/alexisdmacintyre/`.
